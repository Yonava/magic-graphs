# nodeDrag

Handles click-and-drag repositioning of nodes, including dragging a whole multi-node selection at once.

| Export              | Dependencies | Optional dependencies         |
| ------------------- | ------------ | ----------------------------- |
| `nodeDrag(options)` | `canvas`     | `focus`, `marquee`, `history` |

**Controls:** `events`, `lifecycle`

**Events:** `onNodeDragStart`, `onNodeDrop`

**Options:** `recordHistory`
