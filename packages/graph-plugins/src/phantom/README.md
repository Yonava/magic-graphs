# phantom

Renders "ghost" nodes and edges that look real but aren't part of the graph data, useful for previews, hints, and algorithm visualizations.

| Export    | Dependencies | Optional dependencies |
| --------- | ------------ | --------------------- |
| `phantom` | `canvas`     | `focus`               |

**Controls:** `addNode`, `addEdge`, `addElements`, `removeNode`, `removeEdge`, `removeElements`, `nodes`, `edges`, `getNodePosition`
