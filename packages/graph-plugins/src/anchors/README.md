# anchors

Spawns draggable handles around a hovered node so you can pull a new edge out of it, with a live preview line while dragging.

| Export    | Dependencies | Optional dependencies |
| --------- | ------------ | --------------------- |
| `anchors` | `canvas`     | `focus`               |

**Controls:** `theme`, `events`, `lifecycle`

**Events:** `onNodeAnchorDragStart`, `onNodeAnchorDrop`
