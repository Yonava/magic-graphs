# focus

Tracks which nodes and edges are currently selected and themes them accordingly, supporting click, shift-click, and programmatic selection.

| Export  | Dependencies | Optional dependencies |
| ------- | ------------ | --------------------- |
| `focus` | `canvas`     | none                  |

**Controls:** `set`, `clear`, `setAll`, `isFocused`, `focusedNodes`, `focusedEdges`, `theme`, `events`, `lifecycle`

**Events:** `onFocusChange`
