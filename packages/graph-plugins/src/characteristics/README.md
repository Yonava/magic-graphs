# characteristics

Answers structural questions about the graph: is it complete, connected, bipartite; what are its cycles, strongly connected components, and bidirectional edges.

| Export            | Dependencies     | Optional dependencies |
| ----------------- | ---------------- | --------------------- |
| `characteristics` | `adjacencyLists` | none                  |

**Controls:** `isComplete`, `getCycles`, `sccs`, `bidirectionalEdges`, `bipartite`, `connected`
