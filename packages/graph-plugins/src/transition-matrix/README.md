# transitionMatrix

Turns the weighted adjacency list into a node-by-node matrix of exact fractions, for Markov-chain style work.

| Export             | Dependencies     | Optional dependencies |
| ------------------ | ---------------- | --------------------- |
| `transitionMatrix` | `adjacencyLists` | none                  |

**Controls:** the plugin's controls are the matrix getter itself, called as `controls.transitionMatrix()`.
