# marquee

Drag-a-box selection on empty canvas, selecting every node and edge the box encloses.

| Export    | Dependencies      | Optional dependencies |
| --------- | ----------------- | --------------------- |
| `marquee` | `canvas`, `focus` | none                  |

**Controls:** `theme`, `events`, `lifecycle`

**Events:** `onMarqueeBeginSelection`, `onMarqueeEndSelection`
